hubctl / one-page interface

hubctl - interface reference

hubctl is one page: USB Control, a live list of four ports with power, data, voltage, and current. m opens a global menu over the port list; Device is reached from it. Enter on a port is reserved for a future monitor and does nothing in v1. The app sets no background; header and footer are reverse video, and colour appears only on state values.

Selection

Selection is bold reverse video and nothing else: the whole item shares one fill, dark on light, and it is the only selection cue. A filled bar stays obvious in monochrome.

The bar uses bold + SGR 7: background #d0d0d0, foreground #101215. Do not add state colours to it; state colour belongs on the canvas.

Every frame leaves the background unset; the canvas is the terminal's own, shown here as neutral #101215. The header, footer, and selected item use bold reverse video. Colour appears only on state values; with NO_COLOR, no colour is emitted and the words and reverse fills still carry everything. The header state pill stays dark on the light bar so green, amber, and red keep their contrast.
