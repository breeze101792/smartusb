2 · ASCII rendering

ANSI tokens

256-colour SGR when supported, 8-colour otherwise. With NO_COLOR or TERM=dumb, no colour is emitted; the frame and the > marker do not change.

dim — off, residual244 / 90
accent — wordmark81 / 36
ok — ON, live78 / 32
warn — stale, interlock220 / 33
error — lost, failed write203 / 31

Keys

No key writes persistent settings, resets the unit, or acts on more than one channel.

Presentation rules

POWER

Read from 0x00 only. Never inferred from a voltage reading: an off channel reads 202 mV on this unit.

DATA

on, off, or - while VBUS is off. The D+/D− state is not meaningful there.

VOLTAGE

4.61 V from the mV reply. On an off channel: (202 mV), dim, never an output.

CURRENT

0.00 A from the mA reply. Below the accuracy floor still reads 0.00 A.

UNKNOWN

? for any field not received in the last complete poll. Never a stale number.

UNITS

V and A on screen. Raw mV/mA and frame hex go to --trace, not the table.
